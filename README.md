# 💈 MÁFIA BARBER — Landing Page

Landing page desenvolvida para uma barbearia fictícia, com uma identidade visual sofisticada e moderna, combinando tons escuros e detalhes dourados para transmitir exclusividade e profissionalismo.

O projeto foi desenvolvido com foco na experiência do usuário, apresentação dos serviços e facilidade de contato e agendamento.

## 🌐 Demonstração

🔗 **Acesse o projeto:** https://barbearia-sigma-gold.vercel.app/

## 📸 Sobre o projeto

A MÁFIA BARBER apresenta uma experiência digital voltada ao público masculino, com uma interface elegante, navegação intuitiva e elementos visuais que valorizam a identidade da marca.

A página foi estruturada para apresentar os serviços, destacar a experiência da barbearia e facilitar o contato dos clientes.

## ✨ Funcionalidades

- Layout responsivo para desktop e dispositivos móveis.
- Hero section com vídeo de fundo.
- Navegação por seções.
- Apresentação de serviços, preços e duração.
- Botões para seleção de serviços.
- Formulário visual de agendamento.
- Links de contato direto pelo WhatsApp.
- Botão flutuante de WhatsApp.
- Animações e efeitos de entrada com GSAP.
- Efeitos de rolagem com ScrollTrigger.
- Barra de progresso durante a navegação.
- Menu inferior adaptado para dispositivos móveis.
- Respeito à preferência do usuário por movimento reduzido.

## 🛠️ Tecnologias utilizadas

| Tecnologia | Aplicação |
|---|---|
| HTML5 | Estrutura e organização do conteúdo |
| CSS3 | Estilização e responsividade |
| JavaScript | Interatividade e manipulação do DOM |
| Tailwind CSS | Construção da interface |
| GSAP | Animações e transições |
| ScrollTrigger | Animações sincronizadas com a rolagem |

## 🚀 Como executar o projeto

1. Clone o repositório:

```bash
git clone https://github.com/Renato-Rhuan/barbearia.git
```

2. Entre na pasta:

```bash
cd barbearia
```

3. Abra o arquivo `index.html` no navegador ou utilize a extensão Live Server do VS Code.
